# Launch

**Launch 시스템**은 여러 개의 노드를 일일이 터미널에서 실행하지 않고, 하나의 설정 파일을 통해 **다수의 노드를 구성, 설정 및 실행**할 수 있게 해주는 도구입니다.

## 1. 주요 특징

- **다중 노드 실행:** 한 번의 명령으로 여러 노드를 동시에 띄울 수 있습니다.
- **파라미터 관리:** 각 노드에 필요한 파라미터(설정값)를 주입할 수 있습니다.
- **유연성:** Python, XML, YAML 형식을 지원하며, 특히 Python 형식을 사용하면 조건문이나 반복문을 이용한 복잡한 실행 로직을 구현할 수 있습니다.
- **네임스페이스 및 리매핑:** 노드의 이름이나 토픽 이름을 실행 시점에 변경할 수 있습니다.

## 2. Launch 파일 작성 방식 (Python)

가장 권장되는 방식인 Python 기반 Launch 파일은 보통 `generate_launch_description()` 함수를 포함해야 합니다.

```python

from launch import LaunchDescription
from launch_ros.actions import Node

def generate_launch_description():
    return LaunchDescription([
        Node(
            package='turtlesim',
            executable='turtlesim_node',
            output='screen',
        ),
        Node(
            namespace='pub_cmd_vel',
            package='my_first_package',
            executable='my_publisher',
            output='screen'
        )
    ])

```

```python

from launch import LaunchDescription
from launch_ros.actions import Node

def generate_launch_description():

    turtlesim_node = Node(
        package='turtlesim',
        executable='turtlesim_node',
        output='screen',
        parameters=[
            {'background_r': 255},
            {'background_g': 192},
            {'background_b': 203},
        ]
    )

    dist_turtle_action_server = Node(
        package='my_first_package',
        executable='dist_turtle_action_server',
        output='screen',
    )

    return LaunchDescription([
        turtlesim_node,
        dist_turtle_action_server
    ])

```

## 3. 핵심 구성 요소

ROS2 Launch 시스템을 구성하는 주요 개념들은 다음과 같습니다.

| **구성 요소**                | **설명**                                                      |
| ---------------------------- | ------------------------------------------------------------- |
| **Node**                     | 실행할 개별 노드를 정의 (패키지명, 실행 파일명, 노드명 설정). |
| **ExecuteProcess**           | 노드가 아닌 일반 쉘 명령어나 프로세스를 실행할 때 사용.       |
| **DeclareLaunchArgument**    | 실행 시 외부에서 입력받을 수 있는 인수를 정의.                |
| **IncludeLaunchDescription** | 다른 Launch 파일을 불러와서 포함시킬 때 사용 (모듈화).        |
| **GroupAction**              | 여러 노드를 하나의 그룹으로 묶어 네임스페이스 등을 일괄 적용. |

## 4. 실행 방법

터미널에서 `ros2 launch` 명령어를 사용하여 실행합니다.

Bash

```bash
# 기본 실행
ros2 launch <패키지_이름> <파일_이름.launch.py>

# 인수를 넘겨주며 실행하는 경우
ros2 launch <패키지_이름> <파일_이름.launch.py> arg_name:=value
```
