# ROS

ROS(Robot Operating System)는 로봇 애플리케이션의 구축, 배포, 실행 및 유지 관리를 위한 프레임워크, 도구 및 라이브러리를 제공하는 오픈 소스 생태계입니다.

## Framework

ROS 프레임워크는 로봇의 각 부분 간, 그리고 로봇 내부에서 통신을 가능하게 하는 "기반 구조"입니다. 여기에는 메시징, 표준 인터페이스, 다양한 프로그래밍 언어 및 플랫폼 지원이 포함됩니다.

## 구성

ROS는 다음과 같은 기본 구성 요소로 이루어져 있습니다.

- Node
- Interface(Topic, service, action)
- Parameter
- 클라이언트 라이브러리

## Node

독립적으로 수행하는 **최소 단위의 프로그램**을 ROS 2에서는 '노드'라고 부릅니다.

### 노드끼리는 서로 통신합니다

노드들은 혼자 일하지 않고 '클라이언트 라이브러리'를 사용해 서로 통신을 합니다. 세 가지 방식이 있습니다.

- **토픽 (Topic)**
  - **단방향**이면서 **연속적**인 데이터 스트림입니다.
  - **개념:** 정보를 보내는 쪽(Publisher)은 상대방이 누구인지, 잘 받았는지 상관없이 정해진 이름의 통신망에 데이터를 계속 흘려보냅니다. 정보를 받는 쪽(Subscriber)은 그 망에 접속해 데이터를 실시간으로 가져옵니다.
  - **특징:** 일대다(1:N) 통신이 가능하며, 센서 데이터처럼 주기적으로 계속 업데이트되는 정보를 전달할 때 사용합니다.

- **서비스 (Service):**
  - 동기적(Synchronous)이고 **일회성**인 대화입니다.
  - **개념:** 요청(Request)을 보내는 클라이언트와 그에 대한 응답(Response)을 주는 서버로 구성됩니다. 질문을 던지면 반드시 답이 돌아와야 하는 구조입니다.
  - **특징:** 일대일(1:1) 통신이 기본이며, 요청을 보낸 노드는 결과가 올 때까지 기다리는 경우가 많습니다. 특정 기능을 실행하거나 설정을 확인하는 등 '결과 보고'가 필요할 때 사용합니다.

- **액션 (Action):**
  - 서비스와 비슷하지만, 비동기적(Asynchronous)이며 **피드백**이 존재합니다.
  - **개념:** 목표(Goal)를 전달하면, 작업을 수행하는 동안 "현재 몇 % 완료됨" 같은 피드백(Feedback)을 주기적으로 보내고, 최종적으로 결과(Result)를 전달합니다.
  - **특징:** 작업이 진행되는 동안 다른 일을 할 수 있으며, 중간에 작업을 취소할 수도 있습니다. 로봇의 이동이나 정밀한 팔 움직임처럼 시간이 오래 걸리고 중간 확인이 필요한 복합적인 작업에 사용합니다.

### 어디에 있든 상관없이 연결됩니다

노드들은 같은 컴퓨터 안에 있을 수도 있고, 옆에 있는 노트북이나 다른 기기에 있을 수도 있습니다. ROS 2의 스마트한 시스템이 알아서 서로를 찾아내 연결해주기 때문에(분산형 검색), 복잡한 네트워크 설정 대신 '노드가 무엇을 할지'에만 집중하면 됩니다.

### 설정값을 실시간으로 바꿀 수 있습니다

노드는 작동 중에 '파라미터(매개변수)'라는 설정값을 가질 수 있습니다. 로봇을 멈추지 않고도 "속도를 조금 더 올릴까?" 같은 설정을 실시간으로 변경할 수 있게 해주는 편리한 기능입니다.
